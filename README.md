# Job Application Tracker

A beginner-friendly Python project created to practice Python programming by building a simple real-world application.

## About the Project

Job Application Tracker is a menu-driven Python application that allows users to add and manage their job applications in one place.

I built this project as a fresher to strengthen my Python fundamentals and practice writing a small real-world application.

## Features

* Add job application
* View job applications
* Store company name and job role
* Track application status
* Simple menu-driven interface

## Technologies Used

* Python
* Variables
* Input/Output
* Conditional Statements
* Loops
* Functions
* Lists and Dictionaries

## How to Run

Clone the repository and run the Python file:

```bash
python main.py
```

Then follow the options displayed in the terminal.
